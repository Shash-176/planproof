# Project history

PlanProof began on 10 November 2026 as an entry to the BharatCode Build League hackathon, built
on the BharatCode model API. The hackathon has ended. From version 1.0 the project is an
independent open-source tool; the BharatCode integration was replaced by a provider-neutral AI
layer (see [`../AI-PROVIDER.md`](../AI-PROVIDER.md)).

These documents are kept as a record of how the idea was chosen. They describe the plan at the
time, not the current system. For the current design, read [`../ARCHITECTURE.md`](../ARCHITECTURE.md).
